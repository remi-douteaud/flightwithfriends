Comment ça marche

Avant le vol

Chacun ouvre ce lien une fois avec internet : l'appli se met en mémoire et fonctionne ensuite sans réseau. Sur iPhone, « Sur l'écran d'accueil » depuis le menu Partager de Safari ; sur Android, « Installer l'application » dans le menu de Chrome.

Dans l'avion

1. L'hôte (de préférence un Android) active le partage de connexion Wi‑Fi de son téléphone. Aucune connexion internet n'est nécessaire : c'est juste un réseau local.

2. Les autres se connectent à ce Wi‑Fi (ignorer l'avertissement « pas d'internet »).

3. L'hôte crée un salon, puis ajoute les participants un par un : chaque invité scanne le code de l'hôte, puis l'hôte scanne le code de l'invité.

4. Tout le monde discute et joue au quiz. Si l'hôte ferme l'appli, la partie est sauvegardée sur son téléphone : « Reprendre la partie en cours » la relance, les joueurs rescannent son code et retrouvent leurs points.
